# Milestone 6: Business Insights Framework

The analytical layer converts warehouse facts into manufacturing decisions.

## Production Optimization

Measure output trends, production time and cost to identify opportunities for efficiency improvement.

## Quality Improvement

Defect rate analysis helps identify factories, machines and products requiring investigation.

## Cost Management

Cost per unit analysis highlights expensive production processes and supports operational planning.

## Equipment Management

Machine efficiency metrics support maintenance planning and resource allocation.

## Historical Analysis

SCD Type 2 machine history ensures reports remain historically correct after machine assignments change.

## Final Dashboard Deliverable

The Power BI dashboard should demonstrate:

- connected dimensional model
- KPI cards
- interactive filtering
- production trends
- factory comparison
- machine performance analysis
- evidence-based manufacturing recommendations
