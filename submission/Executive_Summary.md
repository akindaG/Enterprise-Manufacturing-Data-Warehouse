# Executive Summary

## Enterprise Manufacturing Data Warehouse

**Author:** Akinda Gunarathne  
**Module:** CCS3307 Data Warehousing

## Project Overview

This project implements a complete Data Warehouse solution for manufacturing production analytics.

The selected business process is **Production Operations Analytics**. The warehouse integrates operational manufacturing data into a dimensional model to support business intelligence and decision-making.

## Solution Summary

The implemented solution includes:

- Manufacturing OLTP source design
- Staging and ETL pipeline
- Star schema data warehouse
- Surrogate key management
- SCD Type 2 historical tracking
- Production analytics
- Dashboard-ready reporting layer

## Key Technologies

- PostgreSQL
- Python
- Pandas
- SQL
- GitHub Actions
- Power BI

## Business Value

The warehouse enables analysis of production efficiency, factory performance, machine utilization, product output and historical operational changes.
